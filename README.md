# Image Studio

**English** | [繁體中文](#繁體中文)

A single-file, fully local image tool: merge multiple images, add padding, slice with freely draggable grid lines, and export a ZIP of JPG/PNG pieces. No backend — images never leave your browser.

**Live demo:** https://Ngqid.github.io/local-image-studio/

## Features
- Add images any time — new images are **appended** to the existing ones, never overwriting them (exact duplicates are skipped)
- Merge vertically or horizontally; reorder by filename, upload order, or drag-and-drop
- Padding with custom background color
- Grid slicing plus free vertical/horizontal lines you can drag
- Export JPG (quality + max width) or lossless PNG (optional original size) as ZIP
- "Clear all" asks for confirmation

## Run locally
Open `index.html` in a browser. Internet access is needed to load Tailwind CSS and JSZip from CDNs.

## Deploy
Served by GitHub Pages from the `main` branch root.

## 繁體中文

單一檔案、完全本機運作的圖片工具：多圖拼接、版面留白、可自由拖曳格線切圖，並以 ZIP 匯出 JPG／PNG。無後端，圖片不會離開你的瀏覽器。

**線上使用：** https://Ngqid.github.io/local-image-studio/

### 功能
- 隨時可新增圖片：新圖片會**加入**現有圖片，不會覆蓋（完全相同的檔案會自動略過）
- 垂直或水平拼接；可依檔名、上傳順序或拖曳排序
- 四邊留白與自訂背景色
- 網格切圖，並可自由新增、拖曳水平／垂直格線
- 匯出 JPG（可調品質與最大寬度）或無損 PNG（可保留原尺寸）ZIP
- 「清除全部」會先跳出確認

### 本機使用
直接用瀏覽器開啟 `index.html`。需要網路以載入 Tailwind CSS 與 JSZip（CDN）。

### 部署
透過 GitHub Pages，由 `main` 分支根目錄提供。
